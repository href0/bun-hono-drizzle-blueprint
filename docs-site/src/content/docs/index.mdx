## Pilar arsitektur

<CardGrid stagger>
  <Card title="Kontrak HTTP seragam" icon="document">
    Envelope respons dan kode error tunggal, wire contract `snake_case` dua arah, pesan dwibahasa. Lihat [HTTP Contract](standards/http-contract/).
  </Card>
  <Card title="Data layer teraudit" icon="setting">
    Repository dasar per jenis tabel; setiap perubahan tercatat atomik. Lihat [Database](standards/database/).
  </Card>
  <Card title="Kanal inbound aman" icon="random">
    Default-deny JWT dengan refresh cookie HttpOnly, kanal inbound bertanda tangan HMAC (webhook vendor, gateway partner opsional) yang fail-closed. Lihat [Auth & Inbound](standards/auth-and-inbound/).
  </Card>
  <Card title="Quality gate berlapis" icon="approve-check-circle">
    Setiap aturan punya penegak mesin (ESLint, dependency-cruiser, test, script). Lihat [Quality Gates](standards/quality-gates/).
  </Card>
</CardGrid>
