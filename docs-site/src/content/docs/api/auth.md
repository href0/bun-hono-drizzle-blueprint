## `POST /api/v1/auth/change-password`

**Change your own password (ends every other session)**

Requires the current password (attempts count like logins → 429). Returns a new access token and sets a new refresh cookie for this device; every other session ends.

- Access token: `Authorization: Bearer <access_token>`

**Header**

| Nama | Tipe | Wajib | Aturan / keterangan |
|---|---|---|---|
| `Accept-Language` | string | tidak | Language of response messages: id \| en (q-values honoured; unsupported or missing = DEFAULT_LOCALE). |
| `X-Request-ID` | string | tidak | pola `^[A-Za-z0-9._:-]{1,128}$`; Correlation id, echoed back and written to every log line. Missing or not matching the pattern = a UUID v7 is generated. |

**Body** (`application/json`)

| Field | Tipe | Wajib | Aturan / keterangan |
|---|---|---|---|
| `current_password` | string | ya | panjang ≥ 1; panjang ≤ 1024 |
| `new_password` | string | ya | panjang ≥ 8; panjang ≤ 1024 |

**Contoh request**

```http
POST /api/v1/auth/change-password
Authorization: Bearer <access_token>
Content-Type: application/json

{
  "current_password": "string",
  "new_password": "xxxxxxxx"
}
```

**200 — Password changed**

Pesan: `Password berhasil diganti; sesi di perangkat lain diakhiri` (en: `Password changed; sessions on other devices have ended`)

```json
{
  "success": true,
  "status_code": 200,
  "message": "Password berhasil diganti; sesi di perangkat lain diakhiri",
  "data": {
    "access_token": "string",
    "token_type": "Bearer",
    "expires_in": 1
  }
}
```

**Error**

| Status | Code | Arti |
|---|---|---|
| 400 | `ERR_INVALID_INPUT` | Input tidak memenuhi skema (lihat `details`) |
| 400 | `ERR_INVALID_JSON` | Body bukan JSON yang valid |
| 400 | `ERR_NON_SNAKE_CASE_KEY` | Key body / query bukan snake_case (`field` = key seperti dikirim) |
| 401 | `ERR_AUTH_TOKEN_EXPIRED` | Access token kedaluwarsa: refresh lalu ulangi |
| 401 | `ERR_AUTH_TOKEN_INVALID` | Access token tidak valid |
| 401 | `ERR_UNAUTHORIZED` | Header `Authorization: Bearer` tidak ada |
| 413 | `ERR_PAYLOAD_TOO_LARGE` | Body melebihi `HTTP_BODY_LIMIT_BYTES` |
| 429 | `ERR_AUTH_LOGIN_LOCKED` | Terlalu banyak percobaan login untuk email ini dari klien ini |
| 429 | `ERR_RATE_LIMITED` | Batas request terlampaui: tunggu `Retry-After` detik |
| 500 | `ERR_INTERNAL` | Error tak terduga di server (detail tidak pernah dikirim) |

## `POST /api/v1/auth/login`

**Log in with email and password**

Returns an access token and sets the refresh token as an HttpOnly cookie. Too many attempts for one email from one client → 429 `ERR_AUTH_LOGIN_LOCKED`.

- Publik (tanpa autentikasi)

**Header**

| Nama | Tipe | Wajib | Aturan / keterangan |
|---|---|---|---|
| `Accept-Language` | string | tidak | Language of response messages: id \| en (q-values honoured; unsupported or missing = DEFAULT_LOCALE). |
| `X-Request-ID` | string | tidak | pola `^[A-Za-z0-9._:-]{1,128}$`; Correlation id, echoed back and written to every log line. Missing or not matching the pattern = a UUID v7 is generated. |

**Body** (`application/json`)

| Field | Tipe | Wajib | Aturan / keterangan |
|---|---|---|---|
| `email` | string (email) | ya | panjang ≤ 255 |
| `password` | string | ya | panjang ≥ 1; panjang ≤ 1024 |

**Contoh request**

```http

Content-Type: application/json

{

}
```

## `POST /api/v1/auth/refresh`

**Get a new access token (rotates the refresh token)**

Reads the `refresh_token` HttpOnly cookie (set by login, sent by the browser with `credentials: "include"`). Cross-site requests are rejected (CSRF: `Origin` must be in CORS_ORIGINS or the API itself; non-browser clients send `Content-Type: application/json`). A token used twice ends the whole session (`ERR_AUTH_REFRESH_REUSED`).

- Publik (tanpa autentikasi)

**Header**

| Nama | Tipe | Wajib | Aturan / keterangan |
|---|---|---|---|
| `Accept-Language` | string | tidak | Language of response messages: id \| en (q-values honoured; unsupported or missing = DEFAULT_LOCALE). |
| `X-Request-ID` | string | tidak | pola `^[A-Za-z0-9._:-]{1,128}$`; Correlation id, echoed back and written to every log line. Missing or not matching the pattern = a UUID v7 is generated. |

**Contoh request**

```http
POST /api/v1/auth/refresh
```

**200 — New access token**

Pesan: `Token akses berhasil diperbarui` (en: `Access token refreshed`)

```json
{
  "success": true,
  "status_code": 200,
  "message": "Token akses berhasil diperbarui",
  "data": {
    "access_token": "string",
    "token_type": "Bearer",
    "expires_in": 1
  }
}
```

**Error**

| Status | Code | Arti |
|---|---|---|
| 401 | `ERR_AUTH_REFRESH_INVALID` | Refresh token tidak ada, kedaluwarsa, atau sudah dicabut: login ulang |
| 401 | `ERR_AUTH_REFRESH_REUSED` | Refresh token lama dipakai ulang: seluruh sesi dicabut |
| 403 | `ERR_CSRF_ORIGIN_FORBIDDEN` | `Origin` tidak diizinkan untuk endpoint ber-cookie (CSRF) |
| 429 | `ERR_RATE_LIMITED` | Batas request terlampaui: tunggu `Retry-After` detik |
| 500 | `ERR_INTERNAL` | Error tak terduga di server (detail tidak pernah dikirim) |
