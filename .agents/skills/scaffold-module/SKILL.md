# Scaffold Feature Module

Use this skill when asked to create, add, or scaffold a new domain/feature module under `src/modules/<module-name>/`.

---

## 1. Mandatory File Structure

Every feature module with write capabilities (`INSERT`, `UPDATE`, `DELETE`) **MUST** include:

```
src/modules/<name>/
├── <name>.controller.ts
├── <name>.controller.test.ts
├── <name>.dto.ts
├── <name>.messages.ts
├── <name>.repository.ts
├── <name>.repository.test.ts
├── <name>.routes.ts
├── <name>.service.ts
├── <name>.service.test.ts
├── <name>.transformer.ts
└── <name>.transformer.test.ts

src/database/schema/domain/
└── <name>.schema.ts
```

---

## 2. Step-by-Step Scaffolding Workflow

### Step 1: Define Module Identifiers
- **Module Name**: `kebab-case` (e.g. `products`, `flight-schedules`).
- **Route Prefix**: `<API_BASE_PATH>/v1/<kebab-case-plural>` (default `/api/v1/products`). The version is code: modules register on the `v1` router in `createApp()`, never with their own `/api/v1` prefix.
- **Table Name**: Plural `snake_case` under schema `domain` (e.g. `domain.products`).
- **Messages constant**: `UPPER_SNAKE` singular + `_MESSAGES` (e.g. `PRODUCT_MESSAGES`) — written `<UPPER_SINGULAR>_MESSAGES` below.

---

### Step 2: Create Drizzle Schema (`src/database/schema/domain/<name>.schema.ts`)

Tables are declared with `appTable` (PostgreSQL `public` — the project owns its database) and take ids and timestamps from the column helpers — ESLint rejects raw `timestamp(`, `date(`, `serial(`, `pgTable(` and `.defaultRandom()` in schema files. `uuidPrimaryKey()` is UUID v7 generated by the app; `timestamps()` gives `created_at` / `updated_at` as `Temporal.Instant`. See `.agents/skills/project-standards/references/database.md`.

```typescript
import { boolean, varchar } from 'drizzle-orm/pg-core';
import { timestamps, uuidPrimaryKey } from '../columns';
import { appTable } from '../schemas';

export const <camelPlural> = appTable('<snake_plural>', {
  id: uuidPrimaryKey(),
  name: varchar('name', { length: 255 }).notNull(),
  isActive: boolean('is_active').default(true).notNull(),
  ...timestamps(),
});

export type <PascalSingular> = typeof <camelPlural>.$inferSelect;
export type New<PascalSingular> = typeof <camelPlural>.$inferInsert;
```

**Re-Export in `src/database/schema/domain/index.ts`:**
```typescript
export * from './<name>.schema';
```

### Step 3: Create DTOs with Zod (`src/modules/<name>/<name>.dto.ts`)

Fields are written in camelCase; clients send them in snake_case (`validate()` rejects any other casing with 400 `ERR_NON_SNAKE_CASE_KEY` and converts accepted payloads). Reuse the shared `uuidParamSchema` (`:id`) and `paginationQuerySchema` (`?page=&per_page=`) from `src/core/dto/common.dto.ts` instead of redefining them. For a free-form dictionary field, pass `preserveKeys: ['<field>']` to `validate()` — request side only: responses still convert dictionary keys to snake_case, so prefer `{ key, value }` arrays.

The response schema documents the endpoint (OpenAPI) and types the transformer, so the docs cannot drift from what the API returns. Instant columns are `isoInstant()`: a `Temporal.Instant` in TypeScript, an ISO 8601 UTC string on the wire (calendar dates: `isoCalendarDate()`).

```typescript
import { z } from 'zod';
import { isoInstant } from '../../core/openapi';

export const create<PascalSingular>Schema = z.object({
  name: z.string().min(1, 'Name is required'),
});

export type Create<PascalSingular>Dto = z.infer<typeof create<PascalSingular>Schema>;

export const <camelSingular>ResponseSchema = z.object({
  id: z.string().uuid(),
  name: z.string(),
  isActive: z.boolean(),
  createdAt: isoInstant(),
  updatedAt: isoInstant(),
});

export type <PascalSingular>Response = z.infer<typeof <camelSingular>ResponseSchema>;
```

### Step 4: Create Messages (`src/modules/<name>/<name>.messages.ts`)

Every user-facing message is a `LocalizedMessage` (`{ id, en }`). String literals passed to `new ApiResponse(...)`, `new XError(...)` or error `details[].message` in `src/modules/**` are rejected by ESLint (only `InternalServerError`, whose text is log-only, may use a plain string). Replace `<PascalSingular>` in the Indonesian texts with the proper Indonesian noun.

```typescript
import type { LocalizedMessage } from '../../core/i18n';

export const <UPPER_SINGULAR>_MESSAGES = {
  CREATED: { id: '<PascalSingular> berhasil dibuat', en: '<PascalSingular> created successfully' },
  RETRIEVED: { id: 'Data <PascalSingular> berhasil diambil', en: '<PascalSingular> retrieved successfully' },
  LIST_RETRIEVED: {
    id: 'Daftar <PascalSingular> berhasil diambil',
    en: '<PascalPlural> retrieved successfully',
  },
} as const satisfies Record<string, LocalizedMessage>;

export const <camelSingular>NotFoundMessage = (id: string): LocalizedMessage => ({
  id: `<PascalSingular> dengan ID '${id}' tidak ditemukan`,
  en: `<PascalSingular> with ID '${id}' not found`,
});
```

### Step 5: Create Repository (`src/modules/<name>/<name>.repository.ts`)

> **ESLint Guard**: DO NOT import `db` directly. Use `TransactionHost`.

```typescript
import { eq, count } from 'drizzle-orm';
import { InternalServerError } from '../../core/errors';
import { TransactionHost, defaultTxHost } from '../../database';
import { <camelPlural>, type <PascalSingular>, type New<PascalSingular> } from '../../database/schema';

export class <PascalPlural>Repository {
  constructor(private readonly txHost: TransactionHost = defaultTxHost) {}

  async findById(id: string): Promise<<PascalSingular> | null> {
    const result = await this.txHost.tx
      .select()
      .from(<camelPlural>)
      .where(eq(<camelPlural>.id, id))
      .limit(1);
    return result[0] ?? null;
  }

  async create(data: New<PascalSingular>): Promise<<PascalSingular>> {
    const result = await this.txHost.tx
      .insert(<camelPlural>)
      .values(data)
      .returning();
    // Drizzle types result[0] as always present; INSERT … RETURNING can still be empty at runtime.
    const created = result[0] as <PascalSingular> | undefined;
    if (!created) {
      // Broken invariant: logged by the error handler, never shown to the client.
      throw new InternalServerError('INSERT returned no rows — unexpected database-level rejection.');
    }
    return created;
  }

  async findAll(limit: number, offset: number): Promise<<PascalSingular>[]> {
    return this.txHost.tx
      .select()
      .from(<camelPlural>)
      .limit(limit)
      .offset(offset);
  }

  async count(): Promise<number> {
    const result = await this.txHost.tx.select({ val: count() }).from(<camelPlural>);
    return result[0]?.val ?? 0;
  }
}

export const <camelPlural>Repository = new <PascalPlural>Repository();
```

import type { <PascalSingular> } from '../../database/schema';

### Step 7: Create Service (`src/modules/<name>/<name>.service.ts`)

```typescript
import { <camelPlural>Repository, <PascalPlural>Repository } from './<name>.repository';
import { NotFoundError } from '../../core/errors';
import type { PaginationQueryDto } from '../../core/dto/common.dto';
import type { Create<PascalSingular>Dto } from './<name>.dto';
import { <camelSingular>NotFoundMessage } from './<name>.messages';
import type { <PascalSingular> } from '../../database/schema';

export class <PascalPlural>Service {
  constructor(private readonly repository: <PascalPlural>Repository = <camelPlural>Repository) {}

  async create<PascalSingular>(dto: Create<PascalSingular>Dto): Promise<<PascalSingular>> {
    return this.repository.create({ ...dto });
  }

  async get<PascalSingular>ById(id: string): Promise<<PascalSingular>> {
    const record = await this.repository.findById(id);
    if (!record) {
      throw new NotFoundError(<camelSingular>NotFoundMessage(id));
    }
    return record;
  }

  async list<PascalPlural>(query: PaginationQueryDto): Promise<{ records: <PascalSingular>[]; total: number }> {
    const offset = (query.page - 1) * query.perPage;
    const [records, total] = await Promise.all([
      this.repository.findAll(query.perPage, offset),
      this.repository.count(),
    ]);
    return { records, total };
  }
}

export const <camelPlural>Service = new <PascalPlural>Service();
```

### Step 8: Create Controller (`src/modules/<name>/<name>.controller.ts`)

> **ESLint Guard**: DO NOT call `c.json()` inside controllers. Return `ApiResponse`.

```typescript
import {
  asyncHandler,
  getValidatedBody,
  getValidatedParams,
  getValidatedQuery,
} from '../../core/middlewares';
import { ApiResponse } from '../../core/response';
import { <camelPlural>Service, <PascalPlural>Service } from './<name>.service';
import { to<PascalSingular>Response, to<PascalSingular>ListResponse } from './<name>.transformer';
import type { PaginationQueryDto, UuidParamDto } from '../../core/dto/common.dto';
import type { Create<PascalSingular>Dto } from './<name>.dto';
import { <UPPER_SINGULAR>_MESSAGES } from './<name>.messages';

export class <PascalPlural>Controller {
  constructor(private readonly service: <PascalPlural>Service = <camelPlural>Service) {}

  create = asyncHandler(async (c) => {
    const dto = getValidatedBody<Create<PascalSingular>Dto>(c);
    const created = await this.service.create<PascalSingular>(dto);
    const responseData = to<PascalSingular>Response(created);

    return new ApiResponse(responseData, <UPPER_SINGULAR>_MESSAGES.CREATED, 201);
  });

  getById = asyncHandler(async (c) => {
    const param = getValidatedParams<UuidParamDto>(c);
    const record = await this.service.get<PascalSingular>ById(param.id);
    const responseData = to<PascalSingular>Response(record);

    return new ApiResponse(responseData, <UPPER_SINGULAR>_MESSAGES.RETRIEVED, 200);
  });

  list = asyncHandler(async (c) => {
    const query = getValidatedQuery<PaginationQueryDto>(c);
    const { records, total } = await this.service.list<PascalPlural>(query);
    const responseData = to<PascalSingular>ListResponse(records);
    const totalPages = Math.ceil(total / query.perPage) || 1;

    return new ApiResponse(responseData, <UPPER_SINGULAR>_MESSAGES.LIST_RETRIEVED, 200, {
      currentPage: query.page,
      perPage: query.perPage,
      totalItems: total,
      totalPages,
    });
  });
}

export const <camelPlural>Controller = new <PascalPlural>Controller();
```

### Step 9: Create Routes (`src/modules/<name>/<name>.routes.ts`)

Every route carries `describeEndpoint()`: the response envelope and the **domain** errors it can return (e.g. 404, 409). Added automatically: 429 and 500 on every route; the request body, parameters, 400 and (with a body) 413 by `validate()`; the common headers by the document builder — never describe them twice. `test/openapi.e2e.test.ts` fails for a route without `describeEndpoint()`. See `.agents/skills/project-standards/references/openapi.md`.

```typescript
import { Hono } from 'hono';
import { paginationQuerySchema, uuidParamSchema } from '../../core/dto/common.dto';
import { validate } from '../../core/middlewares';
import { describeEndpoint } from '../../core/openapi';
import { <camelPlural>Controller } from './<name>.controller';
import { create<PascalSingular>Schema, <camelSingular>ResponseSchema } from './<name>.dto';

const router = new Hono();
const tags = ['<PascalPlural>'];

router.post(
  '/',
  describeEndpoint({
    tags,
    summary: 'Create a <camelSingular>',
    response: { status: 201, description: 'Created', data: <camelSingular>ResponseSchema },
  }),
  validate({ body: create<PascalSingular>Schema }),
  <camelPlural>Controller.create,
);
router.get(
  '/',
  describeEndpoint({
    tags,
    summary: 'List <camelPlural> (paginated)',
    response: { status: 200, description: 'A page', paginatedItem: <camelSingular>ResponseSchema },
  }),
  validate({ query: paginationQuerySchema }),
  <camelPlural>Controller.list,
);
router.get(
  '/:id',
  describeEndpoint({
    tags,
    summary: 'Get a <camelSingular> by id',
    response: { status: 200, description: 'Found', data: <camelSingular>ResponseSchema },
    errors: [404],
  }),
  validate({ params: uuidParamSchema }),
  <camelPlural>Controller.getById,
);

export { router as <camelPlural>Router };
```

### Step 11: Create Co-Located Tests & Verify Quality Gate

Create unit tests covering repository, service, transformer, and controller.

This template is verified mechanically by `bun run verify:scaffold` (also in CI): it generates a probe module from these code blocks and runs every gate. After editing this file, or any core API the template uses, run it.

The templates are formatted for a short module name; line wrapping changes with the name length, so always format before validating:
```bash
bun run format
bun run validate:full
```
Verify that all static checks pass and the coverage gate (`scripts/check-coverage.ts`) passes — every new file must be loaded by a test.
